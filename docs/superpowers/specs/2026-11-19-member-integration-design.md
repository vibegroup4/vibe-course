# 組員版本整合

## 目的

合併組員的互評、接單行事曆、接單統計與棄單紀錄，延續既有 Sites 公開網址與 D1 示範組。同步更新根目錄 spec.md、README、AGENTS、原設計稿、流程圖與 10 至 15 分鐘簡報。

## 採用方式

以目前小組 main 為整合基礎，移植組員版已能透過後端保存的功能。沿用現有 /api/demo、七天分享連結與資料版本檢查，資料表中的案件 JSON 直接擴充評價及時間欄位，舊案件以空評價與原取件日作顯示相容。

組員壓縮檔另有完整的展示碼後端。該方案需要更換 API、設定三組 secrets 與共用所有訪客案件。本次沿用目前的各組示範連結，讓同學繼續免登入操作。正式帳號與真實案件權限列入後續工作。

## 具體改動

- 完成後住戶與得標者各可留一次 1 至 5 星與 300 字以內文字，後端驗證身分、狀態與重複評價。
- 已約定時，住戶取消記 cancelled，得標者棄單記 abandoned。保留成交紀錄，棄單者可看紀錄但後端移除住戶交接和聯絡欄位。
- 行事曆按臺灣原定取件日期列目前代收者的已確認、已完成及棄單案件，手機顯示案件清單。
- 統計可選本週、本月、本季、本年，以臺灣日期計算接單數、棄單數、完成成交金額。舊案無時間紀錄時回退至預約取件日並明示。
- 沿用組員逾時提示方向，補 API 請求逾時和送出失敗後的表單保留。
- 自動截單、最高評價／最低價／隨機配對與自動重發列入後續，組員雲端版目前未實作這些流程。

## 驗收

既有主流程、同時成交保護、跨組隔離須通過。新增互評保存與權限測試、棄單後隱藏交接資訊測試、完成與棄單統計資料測試，並用公開站與手機尺寸檢查行事曆和角色切換。
