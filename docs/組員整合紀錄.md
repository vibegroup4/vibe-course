# 組員內容採用紀錄

2026 年 11 月 19 日。

## 參考來源

「垃圾代收流程介紹.pptx」八頁整理發單、報價、成交、取件、取消、逾期、問題回報和狀態全覽。「vibe-course_202611191419.zip」提供互評、行事曆、統計、棄單及另一套展示碼 API。

## 採用與調整

- 將簡報的每一步驗證、可見資料與例外條件加入規格、流程文件和整合版簡報。
- 移植互評、行事曆、統計畫面及棄單紀錄，接入目前 /api/demo 與 D1。
- 後端驗證一次互評、棄單後欄位遮蔽及狀態限制，並記錄接單、完成、棄單時間。
- API 增加逾時提示，送出失敗保留表單。日期統一使用臺灣時區。
- 原「總收入」改為「完成成交金額」，因為付款由雙方協調。

## 部署與後續

沿用原 Site、各組示範連結與免登入操作。組員的展示碼方案需三組 secret 並更換 API，列作後續方向。正式試用需要個人帳號和案件歸屬。

自動截單、最高評價／最低價／隨機配對、自動重發僅由組員本機前端執行，雲端後端無對應動作，列為後續範圍。

## 相容

既有 D1 表和案件可沿用。無評價視為尚未評價，缺事件時間用取件日回退。舊 cancelled 無法推定取消人，不補算棄單。

原簡報的本機保存和欠缺後端保護等舊說法已在整合版更新成 D1 與版本條件更新。原始附件保持原樣，參考解壓排除 .git 和 .local，最新交付以 README 為準。
